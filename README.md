# andrew-msu.github.io

Research website for Andrew K. Laskowski (Montana State University): https://andrew-msu.github.io/

Plain HTML/CSS served by GitHub Pages from `main` (root). To refresh the publication list from ORCID:

    python3 scripts/update_pubs.py

To add the Zenodo DOI for the subduction preprint, replace the text between the `ZENODO_DOI` comments in `index.html`.
