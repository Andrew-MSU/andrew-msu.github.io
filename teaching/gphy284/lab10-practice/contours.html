4. Contours and SQL

Overview 1 Decimal degrees 2 Georeference 3 Edit 4 Contours

Steps

  1. The lines are 20 m contours from a USGS 3DEP DEM. Index contours are the elevations that divide evenly by 100.
  2. Select them with a WHERE clause. MOD(Contour, 100) = 0 is the pattern. Comparisons, AND, OR, and parentheses work. Quote text with single quotes. Field names may be quoted with double quotes.
  3. With those rows selected, Calculate Field on Type and enter index. Index lines become thicker.
  4. Select the other contours, for example MOD(Contour, 100) <> 0, and set Type to intermediate.

How this maps to ArcGIS Pro

Lab 10 downloads a 10 m DEM from The National Map, then runs Project Raster (Data Management) into Montana State Plane so the horizontal units are meters. Hillshade and Contour (Spatial Analyst or 3D Analyst) use that projected raster. This page shows those two results for a McCartney Mountains clip; the contour interval here is 20 m.

On the Map tab, in the Selection group, open Select By Attributes and write the SQL. With rows selected, run Calculate Field (Data Management, or the field menu in the attribute table) to set Type to index or intermediate. Symbolize Type so index contours use a thicker line. In Pro, Calculate Field updates every row when nothing is selected. This page updates the selection only, so a miss cannot relabel the whole layer.
