3. Split and auto-complete

Overview 1 Decimal degrees 2 Georeference 3 Edit 4 Contours

Steps

  1. Choose Split. Draw a line that starts outside the black-outlined polygon, crosses it, and ends outside it. Press Finish. One finger pans the map; taps add vertices. Pinch to zoom.
  2. Choose Auto-complete. Draw a line whose first and last taps sit on the same existing outline, with the middle bowed into an empty patch (no color). Finish. The new polygon must reuse that edge, not a nearby copy of it.
  3. In the table, set the new row’s Formation to the name of the unit you snapped to. The other rows are the real map-unit names.
Attribute table. Only the new polygon’s formation can be edited.
IDUnitFormation
How this maps to ArcGIS Pro

On the Edit tab, in the Features group, click Modify, then Split (under Divide). Draw a line that crosses the polygon in at least two places and finish the sketch. Both new features keep the original attributes until you change them.

To add a polygon that shares a boundary, click Create, choose the polygon template, and click Autocomplete Polygon (also written AutoComplete Polygon). Sketch the new edge so it touches the existing polygon at both ends. Pro builds the coincident boundary instead of making you trace it. Then type the formation in the attribute table, or use Calculate Field.
